# האפליקציות שלי

מסך בית שמאגד את כל הריפוזיטוריז הציבוריים שלי מ-GitHub כאייקוני אפליקציות לחיצים, בדומה למסך "Apps" בכרום לאנדרואיד. לחיצה על אייקון פותחת את ה-GitHub Pages של אותו ריפו.

הרשימה נטענת בזמן אמת מול GitHub API בכל טעינת עמוד, כך שריפו חדש שנוסף ב-GitHub מופיע כאן אוטומטית — בלי לגעת בקוד.

## טכנולוגיה
- HTML/JS נקי (ללא build step)
- Tailwind CSS (דרך CDN)
- GitHub REST API (`/users/{username}/repos`) לטעינת רשימת הריפואים

## הרצה
פתחו את `index.html` בדפדפן.
